# دليل أدوات واستخدام مشروع Mellow Coffee

## الأدوات والتقنيات المستخدمة

- **HTML5:** بناء محتوى الصفحة وأقسامها ونموذج التواصل.
- **CSS3:** تصميم الألوان والتخطيط المتجاوب والحركات.
- **JavaScript عادي (Vanilla JavaScript):** عرض المنتجات والبحث والتصفية وتشغيل السلة والتحقق من النموذج.
- **LocalStorage:** حفظ محتويات السلة على جهاز الزائر بين الزيارات.
- **واجهات المتصفح:** التحقق من حقول النموذج وتنسيق الأسعار بالدينار العراقي.
- **Google Fonts:** تحميل خطي Playfair Display وDM Sans؛ يحتاجان إلى اتصال بالإنترنت.
- **صور محلية:** صور الواجهة والمنتجات موجودة في `assets/images/` ولا تحتاج إلى اتصال بموقع الصور.
- **Visual Studio Code ومتصفح ويب:** لتحرير الملفات ومعاينة الموقع واختباره.

لا يستخدم المشروع إطار عمل أو قاعدة بيانات أو خادمًا خلفيًا، ولا يحتاج إلى تثبيت حزم أو إعداد عملية بناء.

## تشغيل الموقع واستخدامه

1. افتح مجلد المشروع في Visual Studio Code أو مدير الملفات.
2. افتح `index.html` في متصفح حديث لمعاينة الموقع.
3. انتقل بين الأقسام من شريط التنقل أو زر القائمة في الواجهة الرئيسية.
4. استخدم أزرار التصنيفات وحقل البحث لتصفية المنتجات.
5. اضغط **أضف إلى السلة** لفتح نافذة اختيار الكمية، ثم عدّل العدد وأكّد الإضافة. افتح **السلة** لمراجعة المنتجات والمجموع، واستخدم **إزالة** لحذف منتج.
6. أدخل الاسم والبريد والرسالة في نموذج التواصل. يتحقق المتصفح من الحقول قبل عرض رسالة تأكيد؛ لا تُرسل الرسالة فعليًا إلى بريد أو خادم.

لضمان حفظ السلة باستقرار، شغّل الموقع عبر استضافة مثل GitHub Pages بدل فتحه مباشرة بعنوان `file://`؛ سلوك التخزين المحلي عند فتح الملفات مباشرة قد يختلف باختلاف المتصفح.

## تعديل المحتوى

### تعديل منتج أو إضافة منتج

افتح `js/app.js` وعدّل قائمة `products`. يحتوي كل منتج على الخصائص التالية:

```js
{
  id: "unique-product-id",
  name: "Product name",
  category: "coffee",
  description: "A short product description.",
  price: 5895,
  image: "assets/images/product-image.jpg",
  alt: "Accessible description of the image"
}
```

استخدم تصنيفًا من `coffee` أو `tea` أو `dessert`، وأضف ملف الصورة إلى `assets/images/`. يجب أن يكون `id` فريدًا لكل منتج. قيمة `price` هي بالدينار العراقي، وتُعرض الأسعار من دون أجزاء عشرية.

الأسعار الحالية حُوّلت من الأسعار التجريبية السابقة على أساس تقريبي قدره 1 دولار = 1,310 دينار عراقي، مع التقريب لأقرب دينار. عدّل قيم `price` مباشرة إذا أردت اعتماد أسعار مختلفة.

### استبدال الصور

ضع الصور الجديدة في `assets/images/`، ثم حدّث مسارها في بيانات المنتج داخل `js/app.js`. صور الخلفية الرئيسية وصورة قسم القصة محددة في `css/styles.css`؛ حدّث المسارين هناك عند استبدالها.

### تعديل معلومات التواصل أو التصميم

- معلومات العنوان وساعات العمل والهاتف والبريد موجودة في قسم التواصل داخل `index.html`.
- الألوان والخطوط والتنسيق موجودة في `css/styles.css`.
- نصوص الصفحة والأقسام موجودة في `index.html`.

## النشر على GitHub Pages

ارفع ملفات المشروع ومجلداته إلى مستودع GitHub مع الإبقاء على `index.html` في جذر المشروع. من **Settings → Pages** اختر الفرع ومجلد الجذر (`/root`) كمصدر للنشر. بعد اكتمال النشر، افتح رابط Pages واختبر الصور والتنقل والسلة.

## حدود النسخة الحالية

- السلة تحفظ البيانات في المتصفح الحالي فقط، ولا تُزامَن بين الأجهزة.
- لا يوجد دفع إلكتروني أو إرسال طلبات إلى المقهى.
- نموذج التواصل يتحقق من صحة المدخلات ويعرض تأكيدًا محليًا، لكنه لا يرسل الرسالة.
- صور الموقع محلية، بينما تتطلب الخطوط اتصالًا بالإنترنت لتحميلها من Google Fonts.
